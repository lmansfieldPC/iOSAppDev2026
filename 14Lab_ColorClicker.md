
# App Project: Color Clicker


# Part 1: Tap Counter

How many times can you tap a button in 10 seconds?

## What it has to do

- [ ] Opens on a **Start** button. No game showing yet.
- [ ] Tapping Start begins the game and starts a **10 second countdown**.
- [ ] While playing: one big button, and a count that goes up every tap.
- [ ] The countdown is on screen the whole game.
- [ ] At 0 the game stops. **Tapping does nothing after time is up.**
- [ ] The final count is shown.
- [ ] A button to play again, which puts the count and the clock back.


**Get this checked before going on.**

# Part 2: Color Match

Same file. Same timer. Now the app tells you which colour to tap.

## What changes

The one button becomes **three buttons: Red, Blue, Green.** The app picks one at random and tells you to tap it.

- **Right colour → +1 point**
- **Wrong colour → −1 point**
- Either way, the app immediately picks a new colour.

Still 10 seconds. Highest score wins.

## What it has to do

- [ ] Everything Part 1 did, still working
- [ ] Three buttons, each coloured to match its name
- [ ] The app shows which colour to tap, in words
- [ ] Right answer adds a point
- [ ] Wrong answer takes a point away
- [ ] A new colour is picked after **every** tap, right or wrong
- [ ] The final score shows when time is up
- [ ] Score can go negative. That is allowed.


## Before you turn it in

- [ ] All three buttons work and are the right colours
- [ ] Tapping the right one adds a point
- [ ] Tapping a wrong one takes one away
- [ ] The colour changes after every single tap
- [ ] Taps do nothing once time is up
- [ ] Play again resets the score and the clock
